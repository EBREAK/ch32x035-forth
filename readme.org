* CH32X035 FORTH

** FEATURES

- STC FORTH, ~16KiB FLASH
  - TOS CACHED IN X15 REGISTER
  - WORD HEADER: 1BYTE LENGTH+FLAG, NAME, 2BYTE CODE OFFSET(BIT0 = ROM/RAM TAG)
  - FORTH/TMP REGISTERS (TOS/PSP/RSP) IN X8-X15: ALLOW USE RVC 16BIT INSTRUCTION
- INTERACTIVE REPL ON USART2 115200 8N1 (WITH HW RTS/CTS)
  - ONLY SUPPORT UPPERCASE HEX WITH $ PREFIX NUMBER INPUT ONLY
  - NO ECHO, NO LINE EDITING
- RISCV ASSEMBLER WRITTEN IN FORTH (RV32IMAC)
  - RAW INSTRUCTION WORDS: L.ADDI, W.ADDI, L.JAL, W.JAL, ....
  - SMART INSTRUCTION WORDS: LI, ADDI, LW, SW, BEQ, BNE, CALL, TAIL, ....
- TAIL CALL OPTIMIZATION
  - WORD EXIT: AUTO CONVERT TAIL CALL TO TAIL JMP
  - WORD RECURSIVE: TAIL RECURSION WITHOUT RETURN STACK GROWTH
- CONTROL FLOW: BEGIN AGAIN UNTIL IF THEN
- COOPERATIVE MULTITASKING
  - WORD PAUSE: ROUND-ROBIN TASK SWITCH
  - WORD USER-NEW: CREATE NEW TASK
- WORD ISP-RESET: ENTER WCH ISP BOOTLOADER BY SOFTWARE

** CONNECT

FORTH UART CONSOLE PIN:

#+BEGIN_SRC text
PA0 CTS
PA1 RTS
PA2 TX
PA3 RX
#+END_SRC

** ENTER ISP DOWNLOAD MODE

TYPE THESE WORD INTO REPL

#+BEGIN_SRC forth
ISP-RESET
#+END_SRC

THEN YOU CAN USE WCHISP TOOL DOWNLOAD NEW FIRMWARE
